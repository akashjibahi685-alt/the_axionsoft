# AXION TECHNOLOGIES
### WE BUILD WHAT'S NEXT.
#### Software. Intelligence. Security.

A world-class, production-ready website and administrative content management system engineered for **AXION TECHNOLOGIES** — an independent IT solutions, software engineering, AI, and cybersecurity technology company headquartered in India and delivering for global clients.

---

## Visual & Creative Identity

- **Design Philosophy**: Experimental Swiss Editorial + Modern Technology + Minimal Brutalism.
- **Inspiration Reference**: Unconventional asymmetric editorial grids, oversized typography, high-craft interaction, and generous whitespace.
- **Palette**:
  - Primary Background: `#101010`
  - Secondary Background: `#181818` / `#141414`
  - Text Primary: `#F5F3EF`
  - Text Secondary: `#A5A5A5`
  - Accent Color: `#B6FF5C` (Acid Green / Electric Lime)
  - Architectural Borders: `#262626` / `#303030`

## Core Business Divisions

1. **Software Engineering** (`/services/software`): Distributed event-sourced systems, microservices, gRPC, and resilient high-throughput data pipelines.
2. **Artificial Intelligence & Machine Learning** (`/services/ai-ml`): Production LLM agent orchestration, deterministic RAG pipelines, and self-hosted open-weights inference.
3. **Web Development** (`/services/web-development`): Bespoke digital flagships, Next.js App Router architectures, and WCAG AA accessibility compliance.
4. **Mobile & Desktop Development** (`/services/mobile-development`): High-framerate native and cross-platform clients with offline-first synchronization.
5. **Cybersecurity** (`/services/cybersecurity`): Authorized defensive vulnerability assessments, VAPT, BOLA detection, and zero-trust proxy design.
6. **Cloud & Infrastructure** (`/services/cloud`): Kubernetes multi-region clusters, GitOps Infrastructure-as-Code, and automated disaster recovery.
7. **Proprietary Software & AI Products** (`/products`): Internal developer engines, RAG frameworks, and security scanners.

## Quick Start Instructions

```bash
# 1. Install dependencies
npm install

# 2. Push database schema
npx prisma db push

# 3. Seed initial database data
npx tsx prisma/seed.ts

# 4. Generate SVG schematics & visual assets
npx tsx scripts/generate-assets.ts

# 5. Run tests
npx tsx tests/run-tests.ts

# 6. Start development server
npm run dev
```

## Production Build & Verification

```bash
npm run build
npm start
```
